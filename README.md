# logitalk
Logi Talk Pro — короткий технічний опис

Клієнт-серверний чат. Сервер на сирих TCP-сокетах — простий ретранслятор байтів. Клієнт (CustomTkinter) сам формує й розбирає текстовий протокол, малює UI, керує анімацією.

Протокол (рядок + \n):

Сервер (server.py)
clients = [] — список підключених сокетів
Головний цикл: accept() → кожному клієнту свій Thread(handle_client)
handle_client: recv() → broadcast() усім, окрім відправника; при розриві з'єднання прибирає сокет зі списку й закриває його
Нічого не парсить — просто ретранслює сирі байти далі
Клієнт (MainWindow)
__init__: вікно побудоване через place() (не pack/grid) — потрібно для точних координат анімації; підключення до localhost:8080 в try/except — якщо сервера немає, застосунок просто працює офлайн
Аватарки: create_circular_avatar() — PIL-маска (ellipse у режимі 'L') обрізає фото або згенерований круг з літерою в ідеальне коло; get_chat_avatar() кешує аватарки чужих авторів у user_avatars_cache, щоб не перемальовувати
Бічна панель: toggle_show_menu() (блокує повторні кліки через is_animating) → animate_open_menu()/animate_close_menu() (рекурсивний self.after(10,...), крок 20 px) → on_resize() синхронізує ширину main_frame → create_menu_widgets() додає аватар/поле ніка/кнопку вже після відкриття → save_name() оновлює нік і шле системне повідомлення
Повідомлення: send_message() пакує TEXT@... і шле + показує локально; open_image() кодує файл у base64 і шле IMAGE@...; recv_message() у фоновому потоці читає сокет у буфер, ріже по \n, передає кожен рядок у handle_line(), яка розпаковує TEXT/IMAGE і малює через add_message() (своє — праворуч, чуже — ліворуч)
Потік даних

Клієнт А → TEXT/IMAGE-рядок → сервер → broadcast іншим → recv_message() у кожного → handle_line() → add_message(). Сервер не знає ні про ніки, ні про аватарки — вся логіка чату на клієнті.
